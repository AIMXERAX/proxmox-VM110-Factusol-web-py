# Protección De PHP

La carpeta `/php` está fuera del alcance de cualquier tarea.

- No leer, buscar, analizar, modificar, crear, mover, eliminar ni ejecutar archivos dentro de `/php`.
- Excluir explícitamente `/php` de búsquedas, validaciones, formateos, pruebas y comandos masivos.
- Si una solicitud requiere cambiar `/php`, detenerse y pedir confirmación explícita al usuario antes de continuar.
